# 해빗 타워 — 보상 시스템 (뽑기 상자 · 몬스터 100 · 스킨 · 칭호 · 소리)

2026-09-27 · 도균님 승인

## 목표
습관 인증의 보상으로 뽑기 상자를 준다. 상자에서 몬스터(100마리, 이로치 포함)와 스킨이 나오고, 도감을 채우고, 장착해서 탑 화면을 꾸민다. 칭호는 조건 달성으로 자동 획득. BGM 4곡 + 효과음.

## 규칙
- 상자 3종. 이름표(box id)로 구분:
  - `d:<day>` 매일 상자 — 사진 인증한 날(`days[day].assetId`), `day >= REWARDS_FROM`(배포일). 다시 찍기·방어권 날은 추가 상자 없음.
  - `c:<day>` 커플 상자 — 둘 다 사진 인증한 날(`coupleDays`의 `partnerAssetId` 있는 날), `day >= REWARDS_FROM`. 각자 1개.
  - `b:<n>` 보너스 상자 — 중복 10개마다 1개 (n = 0, 1, …).
- 안 연 상자 = 위 규칙으로 계산한 상자 − 이미 연 상자(`pulls`). 개수를 따로 저장하지 않는다.
- 뽑기: 등급 굴림(일반 70 / 레어 20 / 희귀 8 / 전설 2) → 그 등급의 풀에서 균등 1개 → 몬스터면 이로치 3%.
  - 매일·보너스 상자 풀 = 몬스터 100 + 일반 스킨 40. 커플 상자 풀 = 커플 스킨 10.
  - 결과는 저장 먼저, 연출은 나중(앱을 꺼도 다시 뽑기 불가).
- 중복: 이미 가진 것(이로치는 이로치끼리 따로 셈)이 나오면 `dup: true` 조각 1개. 보너스 상자 수 = floor(중복 수 / 10), 남은 조각 = 중복 수 − 10 × 보너스 상자 수.
- 시작 선물: 초록 달팽이(`snail-green`)는 처음부터 가진 것으로 친다(pull 없음). 장착 기본값.
- 층수 진화(`buddyFor`) 삭제.

## 카탈로그 (`catalog.js`, 순수 데이터)
- 등급 `TIERS`: common 일반 / rare 레어 / epic 희귀 / legend 전설, 가중치 70/20/8/2.
- 몬스터 100: 기본 모양(base) × 색 변형. id = `<base>-<variant>`. 이름은 오리지널(메이플 생김새·이름 복제 금지).
  - 일반 50, 레어 30, 희귀 15, 전설 5(각자 고유 모양).
  - 이로치 = 같은 그림에 `hue-rotate(180deg)` + 반짝이.
- 스킨 40: 캐릭터 색 16(4직업 × 4), 배경 8, 벽돌 8, 깃발 8. 등급 분배 일반 14 / 레어 12 / 희귀 10 / 전설 4.
- 커플 스킨 10(배경·벽돌·깃발): 일반 4 / 레어 3 / 희귀 2 / 전설 1. 커플 탭에만 적용.
- 칭호 12: 조건 계산은 `logic.js` `titles()`. 첫 벽돌, 일주일 개근(7일 연속), 건축가(첫 탑), 마천루 장인(탑 3), 정면돌파(방어권 없이 30층), 백일의 기적(누적 100일), 오뚝이(무너진 뒤 7층), 반짝이 사냥꾼(첫 이로치), 전설의 시작(첫 전설), 수집가(도감 50), 몬스터 박사(도감 100), 환상의 짝꿍(커플 탑 완성).

## 데이터
- 폰: `pulls/<box id>` = `{ item, shiny, dup, at }`. `habit/me.look` = `{ monster, shiny, char, bg, brick, flag, badge }`(없는 칸 = 기본). 백업 파일 `DOC_PATH`에 `pulls/…` 허용.
- 서버(Supabase):
  - `pulls(user_id, box, item, shiny, dup, at)` PK (user_id, box), RLS 본인만. 새 폰 복원용.
  - `profiles.look jsonb` — 상대가 내 모습을 본다.
  - `couples.skin jsonb` `{bg, brick, flag}` — rpc `couple_info`에 포함, `set_couple_skin(skin jsonb)`. 마지막에 바꾼 사람 것.
- 동기화: 기존 방식(매 sync 비교). `pullsToPush(local, rows)`, `pullsToRestore(rows, local)` 순수 함수 + 테스트.

## 화면
- HUD: 달력 · 앨범 · 가방(안 연 상자 있으면 `🎁N`) · 설정 · 🔊.
- 가방 창 탭: 상자(열기 · 조각 N/10) / 도감(200칸, 없는 칸 실루엣, 이로치 ✨ 줄) / 꾸미기(몬스터·캐릭터 색·배경·벽돌·깃발, 커플 탭이면 커플 스킨) / 칭호.
- 상자 연출: 인증 후 쌓기 애니메이션 끝나면 자동으로 뜸 → 탭(흔들림) → 탭(열림, 등급색 빛 + 효과음, 이로치 반짝) → [바로 장착] / [확인]. 닫으면 가방에 남음.
- 탭별 모습: 내 탭 = 내 look. 상대 탭 = 상대 look. 커플 탭 = 두 사람 몬스터 + 각자 캐릭터 색 + 커플 스킨(없는 칸 = 기본).
- 칭호: HUD 제목 옆 작은 뱃지(내 탭·커플 탭엔 내 것, 상대 탭엔 상대 것).
